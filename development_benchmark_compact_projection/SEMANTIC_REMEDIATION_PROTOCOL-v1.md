# Semantic Renderer Remediation Protocol v1

## Question

Does a compiled pack built from typed portable resource classes, recovery
states, and operations reliably activate every current rule when its Codex
adapter renders those semantics into concise natural language?

This is a compiled-only product remediation gate. It is not a new comparison
and cannot establish superiority over the static profile.

## Why this change is justified

The frozen v2.2 comparison showed that the symbolic decision-table pack was
smaller but the compiled agent ignored or misinterpreted generic action labels.
The static profile's natural wording performed better. The unblinded trace
confirmed that the failed compiled run reasoned from repository defaults and
never operationalized the supplied symbols.

The portable artifact now uses closed enums for resource class,
recovery-request state, required operation, and forbidden operation. The Codex
adapter—not the evidence artifact—renders these semantics into direct natural
rules and adds an explicit precedence directive. Unsupported semantic
combinations fail closed. Evidence, consent, lifecycle, revocation, and clause
provenance bindings remain external and unchanged.

## Fresh tasks and ceiling

Three new non-held-out deployment-planning tasks use a fresh action vocabulary,
one for each evidence stage. Each has two diagnostic cases plus neutral and
objective controls. Only the compiled condition is run.

Exactly three saved-ChatGPT subscription target sessions are permitted. The
nine previously completed target sessions plus these three equal the frozen
twelve-target-run ceiling. No judge, comparator rerun, retry, API key,
provider-billed call, or external-validation access is permitted.

## Isolation

The gate reuses the pinned Codex CLI, `gpt-5.6-luna`, medium reasoning,
standard service, target runner, valid v2.1 smoke receipt, independent scorer,
and outer Bubblewrap sandbox. Every task gets a fresh disposable workspace and
configuration. Only `src/transfer_policy.py` is writable. Network, host state,
credentials, ambient instructions, memories, skills, plugins, MCP servers,
prior transcripts, comparator outputs, and sealed Milestone 6 material are
unavailable.

## Pass gate

The semantic renderer passes only if all three target records are valid and
every diagnostic, neutral, and objective scenario passes at every stage.
Target-visible bytes must remain no greater than the frozen strong profile.
Provider-billed calls and external-validation access must remain zero.

A pass establishes that the semantic product correction works on fresh
development tasks within this milestone. It does not retroactively change the
failed v2.2 comparison or support a cross-agent claim.
