# Isolated strong-profile author contract

You are maintaining one excellent static user profile across three sequential evidence stages.

You receive only:

- the exact approved cumulative evidence packet for each stage;
- the permanent project-neutral authoring contract; and
- the previous stage's profile when maintaining a later stage.

You do not receive the compiled release, runtime projection, renderer output, public-development
tasks, fixtures, scorers, mappings, target outputs, scores, prior Milestone 6A target outputs, or
any external-validation material.

Produce all three standalone stage profiles in one session. Preserve every currently active
behavior, necessary scope, exception, supersession, and essential verification requirement.
Remove behavior that is no longer active. Do not include evidence IDs, consent IDs, artifact IDs,
versions, authority labels, study terminology, or unsupported advice. Optimize for clarity,
compactness, and faithful maintenance rather than imitating any unseen comparator.

The author receives the same eligible evidence used to construct the governed release. It receives
no task or result information.
