# Isolated strong-profile reviewer contract

You receive only the exact approved cumulative evidence for all three stages and the author's
three proposed static profiles.

You do not receive the compiled release, runtime projection, renderer output, tasks, fixtures,
scorers, mappings, target outputs, scores, prior target outputs, or external-validation material.

Review all stages in one independent session. Correct omissions, ambiguity, stale behavior, scope
leakage, precedence errors, unsupported content, and unnecessary verbosity. Each approved profile
must remain standalone and must reflect only behavior active at that stage. Do not add study or
provenance metadata to target-visible text.

Return the three approved profiles plus a concise change log. This is the final static material;
there is no tuning after target outputs exist.
