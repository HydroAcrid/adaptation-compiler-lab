# Blind Semantic Route Discrimination v1

This directory preserves the first 120-case matched-contrast route corpus, two blind audits, the
original unreceipted generation from an instrument failure, the accepted receipted generation, and
the unchanged calibration/holdout detector reports.

V1 is immutable. Its explicit “fictional” memory wording caused safe false negatives, so the gate
failed. See `MILESTONE_6A2H_BLIND_ROUTE_DISCRIMINATION.md` for the full progression and result.
