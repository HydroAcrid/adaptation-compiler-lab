# Milestone 6A.3 fair task-channel comparison

This public development benchmark compares the frozen independently maintained strong static
profile with the current compiled adaptation under the corrected exact-once user-task delivery
adapter.

It uses two fresh tasks per evidence stage and one execution per task-condition cell: 12 target
sessions. Automated scenario scoring is primary. A single isolated anonymous judge is secondary
and runs only after all target evidence is complete.

The benchmark uses saved ChatGPT Codex authentication and permits no API-key or provider-billed
call. The separately sealed Milestone 6 external-validation study is not accessed.

Contents are frozen in this order:

1. six task fixtures and manifests;
2. `PREREGISTRATION-v1.json` and checksum;
3. `PUBLIC_PLAN-v1.json`;
4. `EXECUTION_PROTOCOL-v1.md`;
5. `EXECUTION_CONTRACT-v1.json`;
6. schema snapshots;
7. anonymous target results, judge receipt, and unblinded analysis only after execution.
