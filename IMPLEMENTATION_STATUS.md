## Curated Modes Hub

The prior handcrafted three-Mode catalog remains immutable as historical evaluation evidence, but
is no longer the desktop's built-in product catalog. The current development catalog contains
Frontend Studio, Systematic Debugger, and Read-only Security Review assembled from pinned OpenAI,
GitHub, obra/superpowers, and Anthropic skill sources. Each release records source and license
digests, review decisions, capability omissions, clause-level lineage, limitations, and a signed
offline catalog envelope. Foundry intake reads only bounded declarative resources and quarantines
scripts, hooks, dependencies, tools, and symlink escapes without execution.

The React/Tauri interface lists these releases as `curated_unproven`, exposes their sources and
limitations, and creates a task-bound activation preview before managed execution. Static
conformance and upstream popularity do not count as effectiveness. A bounded successor comparison
must improve a specialty diagnostic—not a neutral-control preference—before an exact release can
become `product_evaluated`. No provider-billed run or sealed Milestone 6 access was introduced by
the hub foundation.

## Same-owner offline recovery

The native product can now export one exact custody-signed recovery bundle from Settings and
restore it during first-run onboarding. The encrypted `.temper-recovery` envelope contains the
same Ed25519 identity, AES raw-store key, a consistent governed-ledger snapshot, encrypted raw
payload envelopes, product-owned receipts, and project registration identities. It excludes
provider credentials, API keys, repositories, build outputs, arbitrary logs, and native agent
files. The renderer sees only raw-free counts, fingerprints, project display names, and opaque
native path-selection tokens.

Import authenticates the full bundle before presentation, refuses to overwrite an existing
runtime, requires an explicit current directory for every project, signs custody-authorized
rebindings, rediscovers machine-specific Codex paths, resets Windows interop assumptions, enrolls
the same identity in DPAPI or Keychain, and validates that the restored ledger has a current state.
Staging and final preference binding roll back only the new installation on failure. Learning,
notifications, and launch at sign-in remain off after restore. Decrypted previews expire after ten
minutes and their opaque selections are purged with them.

This is same-owner disaster recovery, not profile import, device synchronization, or shareable
expertise. An offline copy cannot be remotely revoked. Native Windows and macOS code paths exist;
an external clean-machine restore remains part of the later trusted packaging gate. See
[`TEMPER_OFFLINE_RECOVERY.md`](TEMPER_OFFLINE_RECOVERY.md).

historical artifact version was explicitly limited to Codex. A connected Claude card can preview

intent and scope without raw evidence, and replace that project's Claude authorization set for 30

The authorization changes only the target-family check. Subject, project, task, environment,

until reviewed. Competing stale previews fail safely, empty selection signs a revocation, restart

This closes the silent historical-target gap without mutating Core or weakening Codex. It does not
claim that every behavior is semantically portable, install Claude on this host, authorize a live
provider smoke, or access the deferred Milestone 6 study.

## Claude governed hook runtime

The native hook transport now has a concrete no-model local runtime behind its port. It resolves an
invocation only inside one non-overlapping registered project, rehashes Claude's documented native
instruction environment, and checks current project-specific consent posture before capture or
delivery. Exact prompts, final assistant messages, and bounded failure context are encrypted in the
existing AES-256-GCM raw store. Their signed capture receipts deliberately distinguish
`user_authored_input` from untrusted assistant/failure context; capture alone does not call a
semantic interpreter, create Evidence, or approve durable learning.

Projection preparation happens outside the hook request. It uses only cached semantic relations,
applies deterministic native coverage/conflict policy, binds the release, owner, project,
environment and source-chain digests in a raw-free manifest, and issues a five-minute Ed25519
lease held only in memory. A native instruction change invalidates the old lease at the next hook
event without recompilation or target-visible output. The hook path never calls the projection
provider or any model.

Capture and audit receipts are stored in a signed hash-chained append-only local index; decrypted
payload bytes never enter the index. Startup rejects malformed, reordered, cross-owner, or
signature-tampered retained entries, and a mid-run external file change blocks the next append. Focused
Claude tests cover encrypted prompt recovery, exact native deduplication, stale-environment denial,
expired authorization, no-model cached delivery, untrusted outcome/failure capture, project
overlap, and signed-ledger tampering.

The complete Python gate passes with 1,190 tests and two expected platform skips, strict mypy over
