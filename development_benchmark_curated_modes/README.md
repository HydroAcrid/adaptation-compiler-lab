# Curated Mode Foundry screening

`foundry-screening-v1.json` freezes the first bounded comparison for the exact signed development catalog before any target run.

The design uses three conditions on two specialty diagnostics per Mode:

- Core only.
- Declarative upstream-safe material before Temper compilation.
- The compiled curated Mode.

One neutral control per Mode compares Core only with the compiled Mode. This produces 24 maximum fresh Codex subscription runs: eight per Mode. Every run is fixed to Luna/medium, saved ChatGPT authentication, a ten-minute timeout, no API key, no provider-billed call, and no access to the sealed external-validation study.

This stage answers two separate questions:

1. Does the selected public source contain useful task-specific signal?
2. Does Temper preserve or improve that signal while reducing capability assumptions and irrelevant material?

A release cannot pass because of a neutral-control preference. It must improve at least one specialty diagnostic, introduce no objective regression, forbidden operation, or scope leakage, and deactivate completely. The committed file is a preregistration only; it contains no result and no effectiveness claim.
