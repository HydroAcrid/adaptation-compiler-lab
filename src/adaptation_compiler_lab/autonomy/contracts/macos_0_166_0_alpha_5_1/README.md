# Mac desktop Codex 0.166.0-alpha.5.1

The quota/catalog schemas and fourteen app-server snapshots were generated by the exact
Apple Silicon desktop executable identified in the runtime pin. The older admitted 0.157
catalog did not expose the owner's configured model. This contract preserves exact model,
effort, account, capacity, schema and binary checks; it does not introduce a model fallback.

Windows validates file/hash consistency. Native regeneration, request/response behavior,
isolation, packaging and local Keychain setup require separate Mac checks. A matching schema
is not evidence of capture, analysis, native instruction loading or useful personalization.
