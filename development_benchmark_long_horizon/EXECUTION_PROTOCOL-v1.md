1. Require a clean committed branch and verify all frozen digests.
2. Confirm `codex login status` is exactly saved ChatGPT authentication.
3. Reject `CODEX_API_KEY`, `OPENAI_API_KEY`, or a drifted CLI/model/effort.
4. Reproduce the public plan from the private 32-byte seed without printing the mapping.
5. Run reference and seeded-defect scorer conformance before any target session.
6. For each anonymous episode, create a byte-identical disposable fixture and empty temporary
   Codex home.
7. Deliver the condition snapshot only at Turns 1, 5, and 12 through the same user-task envelope.
8. Resume the exact initial thread for all later turns; do not retry an invalid turn.
9. Permit writes only to the current task’s registered source file. Feedback turns get no writable
   file.
10. After each work turn, run the registered visible and independent scorer commands outside the
    target session. Later turns cannot write earlier task files.
11. Encrypt raw JSONL traces, stderr, final responses, and diffs locally. Commit only digests,
    counts, and anonymous outputs suitable for secondary blind judgment.
12. Destroy the disposable workspace, session, and configuration after Turn 15.
13. Freeze both anonymous episode results before condition unblinding.
14. Report cumulative scores at Turns 3, 10, and 15. Automated correctness remains primary.
15. Any external-validation access, ambient-state leakage, thread substitution, retry, missing
    trace, scorer failure, or teardown failure invalidates the comparison.

The maximum target execution is two persistent sessions and 30 turns on `gpt-5.6-luna`, medium
reasoning, Standard service, through saved ChatGPT authentication. Provider-billed calls are zero.
