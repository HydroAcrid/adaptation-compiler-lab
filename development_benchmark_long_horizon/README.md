# Public long-horizon development benchmark

This directory contains the frozen public Milestone 6A.5 design and sanitized results. It uses
fresh subscription-authenticated Codex conversations and does not contain or access the deferred
Milestone 6 external-validation study.

The benchmark compares the frozen Milestone 6A.4 strong profile and compiled material across one
15-turn persistent episode per condition. Work-task order is seed-shuffled within three fixed
causal stages. The condition mapping, seed, raw traces, and session state remain outside Git.

Authoritative design details are in
[`MILESTONE_6A5_DESIGN.md`](../MILESTONE_6A5_DESIGN.md).

No raw target trace, authentication material, randomization seed, or private condition mapping may
be committed here.
